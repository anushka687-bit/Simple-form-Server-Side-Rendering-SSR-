# 📘 Full Stack Development Tasks (Task 1 - Task 6)

## 🧩 Project Overview
This repository contains a series of tasks (Task 1 to Task 6) demonstrating full-stack web development concepts including frontend development, backend development, REST API integration, server-side rendering, authentication, and admin panel functionality.

---

# 📌 Task 1: HTML Structure and Basic Server Interaction

## 🎯 Objective
Learn basic server-side rendering and form handling using Node.js.

## ⚙️ Features
- HTML form creation for user input
- Node.js + Express server setup
- Form submission handling using POST requests
- Server-side rendering using EJS

## 🧠 Outcome
Understood basic client-server interaction and dynamic HTML rendering.

---

# 📌 Task 2: Frontend and Backend Connection

## 🎯 Objective
Connect frontend with backend server.

## ⚙️ Features
- API routes creation
- Data exchange between frontend and backend
- Basic CRUD understanding

## 🧠 Outcome
Learned how frontend communicates with backend using HTTP requests.

---

# 📌 Task 3: Basic CRUD Operations

## 🎯 Objective
Implement Create, Read, Update, Delete operations.

## ⚙️ Features
- Add new data
- Display data
- Update existing data
- Delete data

## 🧠 Outcome
Understood full CRUD workflow using REST principles.

---

# 📌 Task 4: Server-Side Rendering & UI Development

## 🎯 Objective
Improve frontend structure with server-side rendering.

## ⚙️ Features
- Structured UI using HTML/CSS
- Dynamic rendering of pages
- Basic Express routing

## 🧠 Outcome
Learned how server renders dynamic web pages.

---

# 📌 Task 5: REST API Development

## 🎯 Objective
Build proper REST APIs for CRUD operations.

## ⚙️ Features
- REST API endpoints
- JSON data handling
- API testing using Postman

## 🧠 Outcome
Learned API development and backend structuring.

---

# 📌 Task 6: Full Stack CRUD Application (Final Project)

## 🎯 Objective
Integrate frontend with backend using REST APIs.

## ⚙️ Features
- User/Admin authentication 
- REST API integration with frontend
- Full CRUD operations
- Admin dashboard
- Dark mode UI 
- Real-time data updates

## 🔐 Authentication
- Login system for users/admin
- Protected routes using tokens

## 🧠 Outcome
Built a complete full-stack application with frontend-backend integration.

---

# 🛠️ Tech Stack Used
- HTML, CSS, JavaScript
- Node.js
- Express.js
- MongoDB (Mongoose)
- EJS (for SSR)
- JWT Authentication
- Postman (API testing)

---

# 🚀 Final Outcome
This project demonstrates progressive learning from basic HTML forms to a complete full-stack CRUD application with authentication, API integration, and admin panel functionality.

---

# 📌 Note
Each task builds upon the previous one, gradually introducing full-stack development concepts and real-world application structure.
