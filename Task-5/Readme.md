# 🎓 Student Registration System

A modern and responsive **Student Registration System** developed using front-end technologies and RESTful API integration. This project allows users to manage student records efficiently through CRUD operations (Create, Read, Update, Delete).

---

## 📌 Project Overview

The Student Registration System is designed to collect and manage student information in an organized way. Users can register students by entering their personal, academic, and contact details through an interactive form interface.

The application communicates with the server using RESTful APIs and dynamically displays stored student records on the “All Students” page.

## 🚀 CRUD API Operations

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/students` | Fetch all students |
| POST | `/students` | Add a new student |
| PUT | `/students/:id` | Update student details |
| DELETE | `/students/:id` | Delete a student |
